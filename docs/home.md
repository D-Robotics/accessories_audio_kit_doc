# RDK 音频套件用户手册

RDK™ 音频套件是一款支持全双工多通道录音与播放的音频开发套件，适用于回声消除、声源定位、远场拾音等音频处理，可广泛用于智能会议、语音交互、机器人听觉等应用场景。

<img src="https://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/accessories/04_audio_kit/audio-kit-overview.jpeg" alt="RDK 音频套件" width="80%" />

## 核心特性

- **全双工多通道录音与播放**：录音与播放节点独立，支持同时进行
- **USB / I2S 双模式切换**：支持 USB 与 I2S 模式，以及单路或双路 I2S 模式
- **4-Mic / 6-Mic 麦克风阵列**：支持 4 麦或 6 麦阵列，最多 6 路麦克风输入
- **8 通道同步采样**：6 路麦克风输入 + 2 路功放回采反馈
- **宽采样率范围**：支持 8 kHz – 96 kHz 标准采样率
